## The note

> You opened me 47 times today. The leftovers are still there.

The note is 60 characters, inside the gate of 1 to 200 characters.

## Run

```sh
node main.ts
```

Writes the note to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
